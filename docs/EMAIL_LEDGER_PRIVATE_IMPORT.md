# นำเข้าบัญชีรายจ่ายจากอีเมล (เฉพาะในเครื่อง)

**เริ่มนับรายการตั้งแต่ 25 ต.ค. 2569**: ใช้ไฟล์ CSV จากสมุดบัญชีอีเมลของผู้ใช้ ไม่ต้องเปิด Gmail OAuth หรืออัปโหลดเอกสารไปยัง API

1. ดาวน์โหลดไฟล์ `money_tracker_email_ledger_import_2026-10-25.csv` จากบทสนทนา และเก็บไฟล์ไว้ส่วนตัว
2. เปิด Money Tracker → **ตั้งค่า** → **นำเข้าคำชี้แจงจากอีเมล** → เลือก CSV
3. ตรวจยอดรายจ่ายใหม่และจำนวนรายการซ้ำ/ไม่นับ ก่อนกด **ยืนยันเพิ่มรายการ**
4. ดูคำชี้แจง เลขอ้างอิง และลิงก์ Gmail ได้ที่ **รายการ** → แตะ **ดูคำชี้แจงรายการและอีเมลหลักฐาน**
5. สำรองข้อมูล JSON จากการตั้งค่าเป็นระยะ เพราะรายการในเครื่องยังผูกกับ IndexedDB ของเบราว์เซอร์

## ขอบเขตที่บังคับใช้
- นับเฉพาะแถว `สถานะ=ยืนยันรายจ่าย` ที่ยอด `รวมรายจ่าย` เท่ากับ `จำนวนเงิน` และค่าธรรมเนียมเป็นศูนย์ (ต้องตรวจแยกเมื่อมีค่าธรรมเนียม)
- คงกฎ Money Tracker: เติมเงิน Wallet เป็นรายจ่าย; ค่าทางด่วนที่ตัดจากเครดิตเดิมไม่ใช่เงินออกซ้ำ
- แถวรอตรวจ เอกสารประกอบ ใบเสร็จชื่อผู้จ่ายอื่น และรายการไม่ยืนยัน **ไม่เข้ายอดการเงินในแอป**; ยังเก็บอยู่ในไฟล์ต้นทาง ไม่ถูกลบทิ้ง
- เทียบเลขอ้างอิง และชนกันของวัน/เวลา/ยอด; ถ้าอาจซ้ำต้องตรวจเองก่อนเพิ่ม ไม่ overwrite รายการเดิม
- Import ไม่ใช้ `replaceAll` หรือการ restore JSON ที่จะลบประวัติเดิม
- ไม่เก็บข้อมูลจริงของผู้ใช้หรือ CSV ใน GitHub, โค้ด, fixture, CI และ Vercel static bundle; ไฟล์อ่านในเบราว์เซอร์เท่านั้น
- ชนิดหมวดหมู่ที่ยังไม่มีใน App จะนำไปไว้ `อื่น ๆ` พร้อม **หมวดย่อย** ในคำชี้แจง เพื่อไม่เปลี่ยน schema หรือยอดย้อนหลัง
